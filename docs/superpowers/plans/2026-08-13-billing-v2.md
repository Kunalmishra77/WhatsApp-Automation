# Billing v2 — Durations, Offers & Countdown — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add monthly/quarterly/6-month/yearly plan terms with 6mo/1yr offers (struck original) and a days→hours countdown, on top of the shipped monthly-only Razorpay billing.

**Architecture:** Extend `billing_plans` with a term dimension (8 rows) + `subscriptions.term`; add pure helpers (`addMonths`, `TERMS`, `timeLeft`); make checkout/verify/webhook term-aware (period = today + N months, price from the `(plan_key, term)` row); add a term selector + countdown to the billing UI; monthly-normalize admin MRR. Lifecycle (reminder/grace/suspend) is already term-agnostic — untouched.

**Tech Stack:** Next.js 15 routes, Supabase Postgres, TypeScript, Vitest, recharts, Razorpay (fetch). Reuses Project-1 billing + Project-0 `lib/date-range.ts`.

## Global Constraints

- **Money in paise; amounts always from the DB `billing_plans` row, never the client.** Terms:
  monthly(1)/quarterly(3)/half_yearly(6)/yearly(12) months. Seed values (base / total=round(base×1.18) / original_total = months×monthly_total, null when no offer):
  - `whatsapp`: monthly 299900/353882/NULL; quarterly 899700/1061646/NULL; half_yearly 1500000/1770000/2123292; yearly 3000000/3540000/4246584
  - `whatsapp_instagram`: monthly 399800/471764/NULL; quarterly 1199400/1415292/NULL; half_yearly 2000000/2360000/2830584; yearly 4000000/4720000/5661168
- `term` ∈ `('monthly','quarterly','half_yearly','yearly')` everywhere (DB CHECK + TS union). Default `monthly` (backward-safe).
- Countdown timezone = `Asia/Kolkata`. Signature/idempotency/cross-tenant/fail-open guards from Project 1 stay exactly as-is.
- Windows: Bash tool for `npx tsc --noEmit`, `npx vitest run`, `git`. Do NOT run `npx next build`. No live Razorpay in tests.

```ts
import { zonedDayStartUtc } from '@/lib/date-range';
export type Term = 'monthly'|'quarterly'|'half_yearly'|'yearly';
export const TERMS: Record<Term,{months:number,label:string}> = {
  monthly: { months: 1, label: 'Monthly' }, quarterly: { months: 3, label: 'Quarterly' },
  half_yearly: { months: 6, label: '6 Months' }, yearly: { months: 12, label: '1 Year' },
};
export function monthsForTerm(term: Term): number { return TERMS[term].months; }
export function addMonths(dateStr: string, n: number): string {
  const [y, m, d] = dateStr.split('-').map(Number);
  const first = new Date(Date.UTC(y!, (m! - 1) + n, 1));      // month (m-1)+n, day 1 — JS normalizes overflow
  const lastDay = new Date(Date.UTC(first.getUTCFullYear(), first.getUTCMonth() + 1, 0)).getUTCDate();
  first.setUTCDate(Math.min(d!, lastDay));
  return first.toISOString().slice(0, 10);
}
export function timeLeft(periodEnd: string, now: Date, tz = 'Asia/Kolkata') {
  const expiryMs = Date.parse(zonedDayStartUtc(periodEnd, tz));  // IST midnight of the end date
  const remain = expiryMs - now.getTime();
  if (remain <= 0) return { expired: true, days: 0, hours: 0, label: 'Expired' };
  const days = Math.floor(remain / 86_400_000);
  const hours = Math.floor(remain / 3_600_000);
  if (days >= 1) return { expired: false, days, hours, label: `${days} day${days > 1 ? 's' : ''} left` };
  return { expired: false, days: 0, hours, label: `${hours} hour${hours !== 1 ? 's' : ''} left` };
}
// Replace the old addOneMonth body with: export const addOneMonth = (d: string) => addMonths(d, 1);
```
